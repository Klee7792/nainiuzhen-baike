## 四、一句话项目简介

基于 **Compose Multiplatform + miuix** 的《奶牛镇》游戏离线图鉴 App：物品大全 / 配方查询 / NPC 资料（装饰预览规划中），严格像素硬边渲染，Android 正式分发 + iOS 经 GitHub Actions 出未签名 ipa 由巨魔（TrollStore）侧载。
