## 2. 产品目标（一句话）

帮助《奶牛镇》玩家在一个严格遵循 miuix 设计语言的离线 App 中，快速查询**物品、配方、NPC 与装饰**资料，辅助生产规划、交易与好感经营。

## 5. UI 设计稿说明

### 5.1 主页（Home）

| 区域 | 结构 / 交互 |
| --- | --- |
| 顶栏 | 沿用 miuix 顶栏（中文化），无内容标题或显示「奶牛镇百科」 |
| 内容区 | 4 个**菜单卡片**，沿用「Basic Component」整件样式（背景色、内外边距、圆角统一） |
| 卡片内部 | 左侧**正方形**（高约卡片 2 倍中的方形），显示该二级菜单**随机一个素材**；右侧两行：第一行标题（14–16sp 主色）、第二行总结（12sp 次要色） |
| 卡片排布 | 4 卡片**分区式外边距**（如区块间距 16dp），非紧贴；点击进入对应子页 |

### 5.2 物品大全（子页 + dialog）

- **子页顶栏**：左返回 icon｜中搜索框｜右分类 icon（预留）。滚动内容时顶栏缩至 1 icon 高、搜索框缩到两 icon 之间。
- **sticky 分类栏**（搜索框下方，不随顶栏收缩消失）：多选 chip 组 + 实时统计「共 N 个物品」。
- **内容区**：6 列正方形方块，素材居中按比例缩放；下方 11sp 名称（居中、不换行、超长滚动、速度适中）。
- **物品 dialog（居中，4 区块）**：
  1. **名称售价区**：左物品图（=方块大小）；右上名称；其下「售价/价格」上下结构(card b)；右侧 3 张星级卡（白 1.2 / 金 1.5 / 紫 2，四舍五入取整）。无售价物品隐藏价格区。
  2. **描述区**：富文本（颜色/字号标记 + `\n`），`min-height`=平均行高、`max-height`=上限、超出滚动。
  3. **来源区**：`get_way`。
  4. **按钮区**：关闭（点击空白亦可关闭）。

### 5.3 配方查询（子页 + dialog）

- 子页同 5.2（顶栏/收缩/6 列/名称/sticky 分类栏）。
- **配方 dialog（居中，6 区块）**：
  1. 名称区（无售价）
  2. 描述区
  3. `get_way` / 解锁条件
  4. **原料区**：一行 n 列同款卡片，超出横向滚动；**未超出部分绝对居中**（如 5 个展示 4 个居中，不半切）
  5. **产物区**：通常 1 个同款卡片
  6. 按钮区：关闭
  - 原料/产物卡片可点开 → **复用物品 dialog** 查看详情。

### 5.4 NPC 资料（子页 + dialog）

- **子页**：一行 **3 列** NPC 卡片，保持长宽比、单方向缩放填满。
- **NPC dialog（居中，6 区块）**：
  1. **头**：左 NPC 卡（缩至 80%），右 3 行（住址 / 生日 / 好感 max: x 心）
  2. **简介**：人物故事背景，超长内部滚动
  3. **最爱物品**（原料区样式）
  4. **喜欢物品**（同上）
  5. **讨厌物品**（同上；任一为空仍占位，保持 dialog 大小一致）
  6. **按钮**：左「日程」/ 右「关闭」（好感 max=0 → 日程禁用）

### 5.5 日程子页（全页）

| 区域 | 结构 / 交互 |
| --- | --- |
| 标题栏 | 返回 icon + "NPC名称 日程" |
| 筛选区 | 星期(周一~周天) / 天气(晴/雨/雪/台风/节日) / 季节(春夏秋冬) / 婚姻(未婚/已婚)；**各单选 + 必选一项**，默认 周一 / 晴 / 春 / 未婚 |
| 日程区 | 左：匹配到的日程 + 开始时间；右：日程列表（大字=name，小字=startPoint→endPoint 的 sceneName，箭头连接）；`isAstar` 0=未婚 / 1=已婚 |

### 5.6 装饰预览（P1 草案）

- 庄园预览 + 季节切换 + 动态装饰；dialog/页内展示物品摆放预览与季节效果（数据来源见待确认 Q1）。

## 6. 四个开放问题·明确结论与理由

### Q1 子页「分类」多选 vs 单选？统计放哪？
**结论**：**多选**（chip 组，可组合）；默认全选 = 展示全部；统计「共 N 个物品/配方」放在搜索框下方的 **sticky 分类栏右侧**，实时刷新。

**理由**：物品/配方分类多（鱼类/矿石/加工品/野果/畜牧/烹饪/图纸/蔬果…），多选更灵活、支持交叉筛选；sticky 栏不随顶栏收缩消失，统计常驻可见，解决「顶栏收缩后无空间显示统计」的痛点。

### Q2 内容「翻页」还是「滚动」？
**结论**：首版**滚动**；分类栏 sticky 固定在搜索框下方承载统计；翻页/滚动切换列为 **P2**。

**理由**：6 列小方块数量大（数百），滚动比翻页顺滑、不打断浏览流；miuix 顶栏收缩后搜索框变窄，但 sticky 分类栏已解决统计显示问题，无需靠翻页保留标题栏。

### Q3 素材切片是否缓存？清缓存策略？
**结论**：切片结果**缓存至 `data/user/0/包名/cache/`**；按 app **版本号比对**，检测到更新则**自动清除并重切**；设置页**增加「清理缓存」手动按钮**。

**理由**：避免每次启动重切（性能）；版本变更保证切片与代码一致；手动清理作为 debug/异常的兜底手段。

### Q4 各 dialog 描述区块是否给「平均高度」？
**结论**：描述区块设 `min-height` = **全量平均行数高度**，`max-height` = **上限（如 8 行）**，超出滚动；各 dialog 非描述区块结构固定 → 整体大小**相对一致**。

**理由**：纯固定平均高度会让短描述留白过多、长描述仍可能超界；`min + max` 折中既保证 dialog 一致性观感，又保证长内容可读（不截断）。
