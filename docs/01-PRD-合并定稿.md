## 2. 产品目标（一句话）

帮助《奶牛镇》玩家在一个严格遵循 miuix 设计语言的离线 App 中，快速查询**物品、配方、NPC 与装饰**资料，辅助生产规划、交易与好感经营。

## 3. 用户故事

| # | 角色 | 故事 |
| --- | --- | --- |
| US-1 | 玩家 | 主页一键进入各图鉴板块，高效找到想查的内容 |
| US-2 | 玩家 | 「物品大全」搜到物品并看清售价/星级倍率/描述/来源，规划生产与交易 |
| US-3 | 玩家 | 「配方查询」看到原料与产物及解锁条件，知道如何制作 |
| US-4 | 玩家 | 「NPC 资料」看喜好与日程（按星期/天气/季节/婚姻筛选），送礼提升好感 |
| US-5 | 休闲玩家 | 离线秒开、滚动流畅、dialog 大小一致，随时查阅不卡顿 |
| US-6 | 庄园玩家 | （P1）「装饰预览」看庄园摆放与季节/动态效果，规划布局 |

## 5. UI 规格要点（定稿）

- **主页**：miuix 顶栏 + 3 板块独立卡片；左侧素材随机、按比例放大；顶栏滚动展开/折叠。
- **列表子页**：顶栏（左返回｜中搜索框｜右筛选），滚动收起；搜索框高斯磨砂（`LocalTopBarBackdrop` 透传，子页不得自行 `rememberAppBlurBackdrop()`）；计数与网格 12.dp 左对齐。
- **物品 dialog**：名称售价区（本体图 + 售价卡 + 至多 3 星价卡）→ 富文本描述（min=平均行高、max 限高滚动）→ 来源 `get_way` → 按钮行；无标题栏、按钮置底、点击空白关闭。
- **配方 dialog**：名称 → 描述 → 解锁条件 → 原料区（一行 n 列、超出横滚、未超出绝对居中）→ 产物区；原料/产物卡片可嵌套点开。
- **NPC dialog**：头（立绘 120% 144dp + 住址/生日/好感 max `[★] N 心 [★]`）→ 简介（内部滚动）→ 最爱/喜欢/讨厌（空区块占位保持 dialog 一致）→ 按钮行。
- **日程子页**：四维单选必选筛选 + 时间轴（name 大字 + startPoint→endPoint sceneName 箭头连接；isAstar 区分未婚/已婚）。
- **像素硬边铁律**：素材最近邻放大（`FilterQuality.None`）、零模糊，按原图整倍数居中而非拉伸填满；卡片保持简洁无多余装饰。

## 6. 关键产品规则

### 6.1 星价体系（数据驱动，权威结论）

- 判定 key = `ItemInfo.categoryLabel`（已去除「低/中/高级」后缀）；白名单外仅显示普通售价。
- 倍率：白星 ×1.2（lv_2）、金星 ×1.5（lv_3）、紫星 ×2.0（lv_4）；星价值 = `roundToInt(price × 倍率)`。
- 白名单 9 族 → 真实枚举：鲜花类 / 山珍类 / 药材类+珍稀药材 / 鱼类+河鱼+湖鱼+海鱼+珍稀鱼类+虾蟹+贝壳类 / 畜牧产品 / 加工品（仅 base）/ 矿物 / 虫子 / 怪物掉落。
- 旧 PRD 示例类别（蔬菜水果/菜品/图纸产品）在真实枚举中不存在，作废。扩充只需向 `StarPricePolicy.WHITELIST` 加字符串。

### 6.2 物品黑名单（release 隐藏、debug 展示）

`app/src/main/assets/config/item_blacklist.txt`（834 行），运行时唯一过滤点 `AssetManager.loadItems()`：name 含（作废/无用/废弃/测试/测试用）、desc 含（拼接场景使用/不进背包/不需要翻译）、icon=260000 及保留项；NPC 同理 `npc_blacklist.txt`。`composeResources/files/` 下同名副本为失效文件，勿误用。

### 6.3 四个开放问题结论（v1 拍板，沿用至今）

1. 分类**多选** chip + sticky 栏右侧实时统计「共 N 个」；
2. 内容**滚动**（翻页列 P2）；
3. 切片缓存至 cache 目录，**版本号比对自动清缓存** + 设置页手动清理；
4. 描述区块 min（平均行高）+ max（限高滚动），保证 dialog 观感一致。
