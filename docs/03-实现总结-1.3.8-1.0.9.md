## 4. 性能优化成果

| 项 | 成果 |
|---|---|
| **Android 冷启动** | **11052/12071ms → 1423/2042ms**（同一 MuMu 模拟器/同一 pack）：`PlistParser` 重写——外层 `indexOf` 切帧、正则只跑单帧 ~400B，消除 ICU memmove 3.7GB 搬运（6565 帧 × 3MB plist） |
| 切片阻塞 | `SpriteImage`/`NpcPortraitImage`/`StarImage` 全部 `produceState` + IO 异步取图，先占位后替换 |
| 模糊/玻璃性能 | std/ext 分档 + ShaderWarmup + 交互期降级（`glassInteractionDegrade`，当前默认 false） |
| 启动 OOM | `-Xmx8g` 在 13GB 内存机触发 JVM 原生 OOM（症状：EXIT=127/日志戛然而止/daemon 被停），降为 `-Xmx4g` + kotlin daemon `-Xmx2g` |

**核心结论**：App 永不 idle（`FpsTracker` 常驻 `withFrameNanos`）；「卡顿伴随画面完全静止」≠ 着色器编译，需按数据流排查。

## 5. 关键修复档案（教训沉淀）

| 修复 | 根因 → 对策 |
|---|---|
| JSON null 崩溃 | `"target": null` 解析失败 → DTO 数字字段全 `Int?` + `?: 0` 兜底 |
| v3 ANR | 主线程 `loadAll()` 阻塞 >5s → 重 IO 全部 `Dispatchers.IO` |
| 升级 ClassCastException | 同 key 存储类型 Int→Float → `getScaleFloat()` 迁移读取；**同 key 改类型必须迁移** |
| 关于页闪退 | 同一 `layerBackdrop` 重入录制 → 去内层嵌套 |
| 底栏胶囊静止态永久变形（78cc631） | 按速度拉伸项的输入 `velocity` 抬手后不归零 → 残速永驻 → 各向异性拉伸。修复：拉伸乘 `pressProgress` 门控 + `press()` 清残速。方法论：**量几何、再定位缩放源**；把截图当数据（PIL 逐行 RLE + ASCII 渲染 + 已知 dp 反推 px/dp 交叉校验），前两轮怀疑裁切方向全错 |
| 仓库事故（2026-09-18 凌晨） | 沙箱清空 `.git/refs`+reflog、4 个近期提交对象丢失 → `git fetch origin` + `update-ref` + `pack-refs --all` 全量恢复，零损失 |

## 6. 双端发布流程（SOP）

1. **Android**：改 `app/build.gradle.kts` `versionCode/versionName` → 双端编译验证（`:shared:compileAndroidMain` + `:shared:compileKotlinIosArm64 --rerun-tasks`，确认任务真执行）→ 真机安装验收 → commit + push。
2. **iOS**：改 `builds/ios_build_number.txt`（+1，且发布后无需回写，但**下次发布前要再 bump**）→ GitHub Actions `workflow_dispatch` 手动触发 → 下载 ipa artifact → 巨魔安装 → 录屏逐帧验收。
3. **默认值改动**：AppState + Android/iOS store 三处同步，缺一必炸。
4. 真机验收清单模式：每轮改动附 verification checklist 逐项核对（用户的固定协作节奏）。

## 8. 验证方法论（本项目沉淀）

- **Android 真机**：Redmi K40（alioth）无线调试；`adb kill -3 <pid>` trace 在 `/data/anr/trace_00`；`cmd package compile -m speed -f` 一键排除 AOT 因素；`top -H` 会漏 worker 线程别用来下 CPU 结论。
- **iOS**：无模拟器调试 = CI 出包 → 巨魔装 → **录屏逐帧**（ffmpeg `-fps_mode passthrough`）；应用内 FPS 计数器不可信。
- **像素级 UI 验收**：把截图当数据——PIL 逐行 RLE + 参考色分类渲染 ASCII 图 + 已知 dp 尺寸反推 px/dp 交叉校验（底栏胶囊变形即靠此定位）。
