## 2. 数据层

- **配置家族**（打包进 `app/src/main/assets/config/`）：`item_database.json`（5125 ids）、`npc_database.json`、`compound_unlocks.json`（配方解锁）、`icon_mapping.json`（id→icon 名映射，未记录则 `id.png`）、`item_blacklist.txt`（834 行）/`npc_blacklist.txt`（release 隐藏、debug 展示）。
- **黑名单过滤**：运行时唯一过滤点 `AssetManager.loadItems()`（name/desc 关键词、icon=260000、保留项）。
- **素材保护**：游戏素材一个字节不进公开仓；打包为 **`assets.pack`** 单容器（NZPK v2：魔数破坏 + 哈希改名 + XOR + 偏移索引），存私有仓 `Klee7792/nainiuzhen-assets` Release 附件，CI 用 fine-grained PAT（仅 contents:read）拉取。
- **资源读取**：`expect fun readAssetBytes(path)` — Android 走 `AssetManager.open`（composeResources 资源不合并进纯 Android `:app`，已弃用，`composeResources/files/` 为死数据）；iOS 先查 pack 再回退 NSBundle。
- **DTO 健壮性**：原始 JSON 数字字段一律 `Int?`，mapping 时 `?: 0` 兜底（v2 null 崩溃教训）。

## 3. 素材管线（切片/缓存/渲染）

```
assets.pack / assets/res → PlistParser（plist 图集帧解析）
  → SpriteSlicer（Android: Bitmap；iOS: skiko；rotated 帧交换 w/h + 顺时针还原 + sourceColorRect 偏移贴回 sourceSize 画布）
  → 版本化缓存（cache/version.txt 与版本号比对，不符全量重切；设置页手动清理）
  → SpriteImage / NpcPortraitImage / StarImage（produceState + Dispatchers.IO 异步取图，先占位后替换）
```

- **渲染铁律**：最近邻放大 `FilterQuality.None`、零模糊、整倍数居中不拉伸。
- **倍率体系**：`SpriteScaleContext` 5 上下文（Card/Home/DialogBody/DialogRecipe/DialogFavHate），SharedPreferences 存 Float，设置子页滑块 0.1/0.5/1 步长即时联动；背景卡片固定尺寸不随倍率缩放。
- ⚠️ **SharedPreferences 同 key 改存储类型必须做迁移读取**（`getScaleFloat()` 扩展），否则升级即崩（ClassCastException 教训）。
- ⚠️ **PlistParser 大文本禁用 Kotlin `Regex`**：ICU `Matcher.reset` 会整份输入 memmove 进 native，`findAll` 每匹配新建 Matcher，代价 O(匹配数×文本长度)（曾致安卓冷启动 +10.4s）。先 `indexOf` 切小块再解析。

## 4. 关键子系统

### 4.1 主题与设置
- `colorMode`（0 系统/1 深色/2 浅色）× `monet` 组合 6 态；`AppState` 单一数据源。
- ⚠️ **默认值改动必须三处同步**：`AppState` + `IosAppSettingsStore` + `AndroidAppSettingsStore`。
- 设置持久化：Android SharedPreferences / iOS NSUserDefaults（`AppSettingsStore` 接口）。

### 4.2 导航与大屏适配
- 双层导航：`MainScreen`（底栏 2 页：主页/设置）+ `SubPageNavHost`；子页全页路由（详情/日程/关于/素材缩放）。
- **大屏适配**（定稿 2026-09-13）：判定用 `LocalWindowInfo.containerDpSize`（断点 1200/840/600dp，零新增依赖）；自适应网格规则「单卡 ≥ minCard 的最大列数」（物品/配方 47dp、NPC 104dp），列数不封顶；详情弹窗**三分区**（`DialogSizing.kt`）+ 强制底部贴合，横屏矮屏按钮永可见；「手机横屏」开关默认关（运行时 `setRequestedOrientation`）；宽≥840dp 且 高≥480dp 走列表-详情分栏。

### 4.3 液态玻璃底栏（iOS 风格）
- `ui/components/liquid/` 5 文件：DampedDragAnimation / InteractiveHighlight / CombinedBackdrop / InnerShadow / IosLiquidGlassNavigationBar（自 miuix demo 移植）。
- 交互：折射/高光/按住拖动切换页签/选中果冻弹跳；胶囊按拖动速度各向异性拉伸（**已修复**：拉伸项乘 `pressProgress` 门控 + `press()` 清残速，静止态严格 1:1，见 78cc631）。
- 模糊体系：`rememberAppBlurBackdrop()` 共享 backdrop；顶栏/搜索框/日程筛选区采样同一 backdrop 的 `textureBlur`；⚠️ 子页不得自行 remember（未挂载采样恒空）；⚠️ 应用内 FPS 计数器在 `parallelRendering` 下不可信，iOS 性能验证只能录屏逐帧（ffmpeg `-fps_mode passthrough`）。

### 4.4 富文本引擎
- 两种格式：`/#RRGGBB#内容/#`（无字号）与 `/#RRGGBB#SIZE#内容/#`（SIZE=sp）；`\n` 换行；`RichTextParser` 区分两种形态（v9 修复过混淆误判）。

## 5. 仓库 / CI / 发布

### 5.1 仓库结构
- 公开码仓 = `nainiuzhen-baike/` 内容；外围（素材/日志/工具）一律不进仓库。
- ⚠️ 素材绝不进公开仓：`app/src/main/assets/{config,res}/`、assets 根散文件；commonMain 禁用 `Res.drawable.*`/`painterResource(Res...)`，统一 `LocalSpriteRepository.current.getAssetImage(path)`。

### 5.2 CI（GitHub Actions）
- Android job：PAT 拉 pack → `assembleRelease` → artifact。
- iOS job：**`workflow_dispatch` 手动触发，push 不出包**；macos runner + `CODE_SIGNING_ALLOWED=NO` → Payload → 未签名 ipa artifact → 巨魔侧载。

### 5.3 版本号机制
- **Android**：CI 不计算，直接改 `app/build.gradle.kts` 的 `versionCode/versionName`（当前 38 / 1.3.8）；`builds/build_number.txt`=38 仅台账。
- **iOS**：`builds/ios_build_number.txt`（当前 8）⇒ 下次 CI：**code = n+1**，`name = (code/100+1).(code%100/10).(code%10)` ⇒ 1.0.9/build 9；CI 取值后不回写，发布后必须手动 bump。查上一版是否已出的可靠办法：GitHub API `actions/runs` 看 head_commit。

## 6. 工程红线（血泪总结，接手必读）

1. ⚠️ **写文件/构建必须非沙箱执行**（沙箱曾删真实 .kt）；Bash 环境缺常用命令，文件与 git 操作用 Python `subprocess`（git 用 `C:\Program Files\Git\cmd\git.exe` + `cwd=`，路径写 `D:/...`）。
2. ⚠️ **禁 `git gc`**（本沙箱环境会摧毁仓库）；改历史只用 filter-repo。
3. ⚠️ `BUILD SUCCESSFUL` ≠ 真编译：确认任务真执行 + APK mtime 是本次（13GB 内存机器假成功高发；`-Xmx8g` 会 JVM 原生 OOM，现为 `-Xmx4g` + kotlin daemon 2g）。
4. ⚠️ 大文本禁用 Kotlin `Regex`（见 §3）。
5. ⚠️ 默认值三处同步（见 §4.1）。
6. ⚠️ App 永不 idle：`MainScreen` 的 `FpsTracker.start()` 常驻 `withFrameNanos` 循环——「卡顿=完全静止画面」不是 idle，别按 idle 思路排查。
7. 验证 iOS 性能只能录屏逐帧；`adb kill -3 <pid>` 的 trace 在 `/data/anr/trace_00`；`top -H` 会漏 worker 线程；别 `adb kill-server`。
